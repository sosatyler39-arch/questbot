Welcome to Questbot

Summon this popup any time with Ctrl+Q (rebindable in Settings ⚙️). It hides itself again after 30 seconds of inactivity.

Set Elden Ring to Borderless Windowed

Questbot's overlay is a regular always-on-top window, not an in-game render — Windows only lets it draw on top of the game in Borderless Windowed mode. In true exclusive Fullscreen, this popup won't be visible.

Set this from Elden Ring's own Display settings before playing with Questbot open.

How answers work

When you ask a question, Questbot takes one screenshot of the game window at that moment and sends it with your question, so answers can use what's on your screen. Nothing is captured at any other time by default.

Continuous memory (optional)

If you turn it on, Questbot keeps a rolling local buffer of screenshots from the last few minutes (one every 5 seconds), so answers can use recent context — not just the current moment.

  • The buffer stays on this device; frames are only sent when you ask a question.
  • A red recording dot is always visible while it's on.
  • It's off by default and stays off until you consent here.
