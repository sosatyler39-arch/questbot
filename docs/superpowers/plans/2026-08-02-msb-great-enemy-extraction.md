# Great Enemy Position Extraction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract real in-game positions for the 19 surface-layer `great-enemy` map pins and recalibrate them (and, incidentally, refresh the existing 117 anchors' fit) using the same affine-calibration pipeline built for Sites of Grace.

**Architecture:** A C#/.NET tool resolves each target creature's display name to its chr (character model) ID via `NpcParam`/`NpcName.fmg`, then scans every MSB map file for `Enemy` parts matching that chr ID, producing a raw candidate-placement JSON. A small set of pure TypeScript functions disambiguate multiple candidates per creature using each region's already-known map tiles (from Stage 1's Sites of Grace data) and, when that's not enough, nearest-existing-pin distance. A disposable script merges the resolved positions into `calibration-anchors.json`; another disposable script re-fits and re-applies per-region affine transforms to both `locations.ts` files, exactly as Stage 4 did.

**Tech Stack:** C#/.NET 9 (SoulsFormatsNEXT, already vendored), TypeScript/Node (`tsx`), `node:test`.

## Global Constraints

- Scope is the 19 `great-enemy` pins with `layer: 'surface'` in `web/src/map/locations.ts`. The 5 `layer: 'underground'` great-enemy pins (Mimic Tear, Regal Ancestor Spirit, Valiant Gargoyles, Astel, Lichdragon Fortissax) and all evergaols are explicitly out of scope.
- No third-party boss/entity datasets may be used at any point (the `soulsmods.github.io` entity dataset was evaluated and rejected earlier this session due to its ToS). All name/position data must come from the game's own files.
- Name resolution against FMG text must use **exact equality**, never substring/`Contains` — a substring search incorrectly matches "Tree Sentinel" inside "Draconic Tree Sentinel".
- Build the C# tool via `& "C:\Program Files\dotnet\dotnet.exe" build -v quiet` from `tools/msb-extractor/` (the `dotnet` on PATH resolves to a broken x86 shim with no SDKs in this environment — always use the full path). Run the compiled `.exe` directly (`tools/msb-extractor/bin/Debug/net9.0/msb-extractor.exe`), never `dotnet run` (blocked by this environment's permission classifier) or `dotnet somedll.dll` (breaks native Oodle DLL resolution).
- `web/src/map/locations.ts` and `client/src/renderer/map/locations.ts` must stay byte-identical after every edit — both get the same corrections applied the same way.
- Server-side TypeScript modules use ESM with explicit `.js` extensions on relative imports (`type: module` in `server/package.json`).

using SoulsFormats;

string gamePath = @"C:\Program Files (x86)\Steam\steamapps\common\ELDEN RING\Game";

    ["Flying Dragon Agheel (site)"] = "Flying Dragon Agheel",

    ["Magma Wyrm Makar (site)"] = "Magma Wyrm Makar",
    ["Glintstone Dragon Smarag (site)"] = "Glintstone Dragon Smarag",
    ["Glintstone Dragon Adula (site)"] = "Glintstone Dragon Adula",
    ["Elder Dragon Greyoll (site)"] = "Elder Dragon Greyoll",
    ["Flying Dragon Greyoll (post-quest site)"] = "Flying Dragon Greyoll",
    ["Decaying Ekzykes (site)"] = "Decaying Ekzykes",
    ["Fallingstar Beast (site)"] = "Fallingstar Beast",
    ["Magma Wyrm (site)"] = "Magma Wyrm",
    ["Godskin Apostle (Dominula site)"] = "Godskin Apostle",
    ["Draconic Tree Sentinel (site)"] = "Draconic Tree Sentinel",
    ["Borealis the Freezing Fog (site)"] = "Borealis the Freezing Fog",
    ["Full-Grown Fallingstar Beast (site)"] = "Full-Grown Fallingstar Beast",
    ["Fire Giant (site)"] = "Fire Giant",
    ["Great Wyrm Theodorix (site)"] = "Great Wyrm Theodorix",
    ["Dragonlord Placidusax's Arena"] = "Dragonlord Placidusax",
};

// FromSoftware's nameId convention for these unique creatures: nameId = 90_{chrId:D4}_{suffix:D3}.
// Verified against Godrick (nameId=904750000 -> chr4750, cross-checked against Stormveil's real
// MSB Enemy part "c4750_9000") and against this game's own dragon-family clustering.
static int? DecodeChrId(int nameId)
{
    if (nameId < 900000000 || nameId > 999999999) return null;
    return (nameId % 10_000_000) / 1000;
}

var creatureChrIds = new Dictionary<string, HashSet<int>>();
foreach (var creatureName in pinToCreatureName.Values.Distinct())
{
    var set = new HashSet<int>();
    foreach (var kvp in npcNamesById)
    {
        if (kvp.Value.Equals(creatureName, StringComparison.OrdinalIgnoreCase))
        {
            var chrId = DecodeChrId(kvp.Key);
            if (chrId is int c) set.Add(c);
        }
    }
    creatureChrIds[creatureName] = set;
}

// Elder Dragon Greyoll / Flying Dragon Greyoll have no NpcName.fmg entry at all (verified: zero
// substring matches for "Greyoll" anywhere in that FMG). Fall back to EventTextForMap.fmg, in the
// same menu.msgbnd.dcx bundle, using the same exact-match technique.
foreach (var creatureName in new[] { "Elder Dragon Greyoll", "Flying Dragon Greyoll" })
{
    if (creatureChrIds[creatureName].Count > 0) continue;

    string menuMsgBndPath = Path.Combine(gamePath, "msg", "engus", "menu.msgbnd.dcx");
    BND4 menuMsgBnd = BND4.Read(menuMsgBndPath);
    var eventTextFmgFile = menuMsgBnd.Files.FirstOrDefault(f => f.Name.EndsWith("EventTextForMap.fmg", StringComparison.OrdinalIgnoreCase));
    if (eventTextFmgFile == null) continue;

    FMG eventTextFmg = FMG.Read(eventTextFmgFile.Bytes);
    foreach (var entry in eventTextFmg.Entries)
    {
        if (!string.IsNullOrWhiteSpace(entry.Text) && entry.Text.Equals(creatureName, StringComparison.OrdinalIgnoreCase))
        {
            var chrId = DecodeChrId(entry.ID);
            if (chrId is int c) creatureChrIds[creatureName].Add(c);
        }
    }
}

Console.WriteLine("--- Resolved chr IDs per creature ---");
foreach (var kvp in creatureChrIds)
{
    string marker = kvp.Value.Count == 0 ? "  *** UNRESOLVED ***" : "";
    Console.WriteLine($"  {kvp.Key}: {{{string.Join(", ", kvp.Value)}}}{marker}");
}

// Reverse lookup: chrId -> creature name(s). A chr ID can be shared by near-identical species
// (e.g. Glintstone Dragon Smarag and Adula both use chr4502) so this must be one-to-many.
var chrIdToCreatures = new Dictionary<int, List<string>>();
foreach (var kvp in creatureChrIds)
{
    foreach (var chrId in kvp.Value)
    {
        if (!chrIdToCreatures.TryGetValue(chrId, out var list))
        {
            list = new List<string>();
            chrIdToCreatures[chrId] = list;
        }
        list.Add(kvp.Key);
    }
}

// Scan every small-tile ("_00") MSB file for Enemy parts matching a target chr ID. "_10"/"_99"
// suffixed files are duplicate LOD/resolution variants of the same physical placement (same rule
// Stage 2's tileToWorld() applies) so they're skipped here rather than producing duplicate hits.
string mapStudioDir = Path.Combine(gamePath, "map", "mapstudio");
var nameChrPattern = new Regex(@"^c(\d{4})_", RegexOptions.Compiled);
var candidatesByCreature = new Dictionary<string, List<(string mapTileId, string partName, float x, float y, float z)>>();
foreach (var creatureName in creatureChrIds.Keys)
{
    candidatesByCreature[creatureName] = new List<(string, string, float, float, float)>();
}

int filesScanned = 0;
foreach (var msbPath in Directory.GetFiles(mapStudioDir, "*.msb.dcx"))
{
    string mapTileId = Path.GetFileNameWithoutExtension(Path.GetFileNameWithoutExtension(msbPath));
    if (!mapTileId.EndsWith("_00")) continue;

    MSBE msb;
    try { msb = MSBE.Read(msbPath); }
    catch { continue; }
    filesScanned++;

    foreach (var enemy in msb.Parts.Enemies)
    {
        var match = nameChrPattern.Match(enemy.Name);
        if (!match.Success) continue;
        int chrId = int.Parse(match.Groups[1].Value);
        if (!chrIdToCreatures.TryGetValue(chrId, out var creatureNames)) continue;

        foreach (var creatureName in creatureNames)
        {
            candidatesByCreature[creatureName].Add((mapTileId, enemy.Name, enemy.Position.X, enemy.Position.Y, enemy.Position.Z));
        }
    }
}

Console.WriteLine($"\nScanned {filesScanned} small-tile MSB files.");
Console.WriteLine("\n--- Raw candidates per creature ---");
foreach (var kvp in candidatesByCreature)
{
    Console.WriteLine($"  {kvp.Key}: {kvp.Value.Count} candidate(s)");
}

var output = pinToCreatureName.Select(kvp => new
{
    pinName = kvp.Key,
    creatureName = kvp.Value,
    chrIds = creatureChrIds[kvp.Value].ToArray(),
    candidates = candidatesByCreature[kvp.Value].Select(c => new
    {
        mapTileId = c.mapTileId,
        partName = c.partName,
        localX = c.x,
        localY = c.y,
        localZ = c.z,
    }).ToArray(),
}).ToArray();

Directory.CreateDirectory("output");
string outputPath = Path.Combine("output", "great-enemy-candidates.json");
File.WriteAllText(outputPath, JsonSerializer.Serialize(output, new JsonSerializerOptions { WriteIndented = true }));
Console.WriteLine($"\nWrote {output.Length} pin entries to {outputPath}");

```typescript
import { tileToWorld } from './msb-coordinates.js';
import { applyAffineTransform, type AffineTransform } from './affine-fit.js';

export interface RawCandidate {
  mapTileId: string;
  partName: string;
  localX: number;
  localY: number;
  localZ: number;
}

export interface PinCandidates {
  pinName: string;
  creatureName: string;
  chrIds: number[];
  candidates: RawCandidate[];
}

export interface LocationInput {
  name: string;
  category: string;
  regionId: string;
  fx: number;
  fy: number;
}

export interface GreatEnemyAnchor {
  name: string;
  category: string;
  regionId: string;
  existingFx: number;
  existingFy: number;
  worldX: number;
  worldZ: number;
  matchConfidence: 'clean' | 'tiebreak';
}

export interface GraceForTileSet {
  graceName: string;
  mapTileId: string;
}

export interface AnchorForTileSet {
  name: string;
  regionId: string;
}

/**
 * For each region, the set of map tiles its own (already-extracted) Sites of Grace resolved to.
 * Used to disambiguate which of several chr-ID candidates for a great enemy actually belongs to
 * a given region.
 */
export function buildRegionTileSets(
  graces: GraceForTileSet[],
  anchors: AnchorForTileSet[],
): Map<string, Set<string>> {
  const regionIdByName = new Map(anchors.map((a) => [a.name, a.regionId]));
  const result = new Map<string, Set<string>>();

  for (const grace of graces) {
    const regionId = regionIdByName.get(grace.graceName);
    if (!regionId) continue;

    let tiles = result.get(regionId);
    if (!tiles) {
      tiles = new Set<string>();
      result.set(regionId, tiles);
    }
    tiles.add(grace.mapTileId);
  }

  return result;
}

export function matchGreatEnemies(
  pinCandidates: PinCandidates[],
  locationsByName: Map<string, LocationInput>,
  regionTileSets: Map<string, Set<string>>,
  regionTransforms: Map<string, AffineTransform>,
): { anchors: GreatEnemyAnchor[]; unresolved: string[] } {
  const anchors: GreatEnemyAnchor[] = [];
  const unresolved: string[] = [];

  for (const pin of pinCandidates) {
    const location = locationsByName.get(pin.pinName);
    if (!location) {
      throw new Error(`No location entry found for pin "${pin.pinName}"`);
    }

    const allowedTiles = regionTileSets.get(location.regionId) ?? new Set<string>();
    const filtered = pin.candidates.filter((c) => allowedTiles.has(c.mapTileId));

    if (filtered.length === 0) {
      unresolved.push(pin.pinName);
      continue;
    }

    let chosen = filtered[0];
    let confidence: 'clean' | 'tiebreak' = 'clean';

    if (filtered.length > 1) {
      confidence = 'tiebreak';
      const transform = regionTransforms.get(location.regionId);
      if (!transform) {
        throw new Error(`No affine transform available for region "${location.regionId}"`);
      }

      let bestDistance = Infinity;
      for (const candidate of filtered) {
        const { worldX, worldZ } = tileToWorld(candidate.mapTileId, candidate.localX, candidate.localZ);
        const { fx, fy } = applyAffineTransform(transform, worldX, worldZ);
        const distance = Math.hypot(fx - location.fx, fy - location.fy);
        if (distance < bestDistance) {
          bestDistance = distance;
          chosen = candidate;
        }
      }
    }

    const { worldX, worldZ } = tileToWorld(chosen.mapTileId, chosen.localX, chosen.localZ);
    anchors.push({
      name: pin.pinName,
      category: location.category,
      regionId: location.regionId,
      existingFx: location.fx,
      existingFy: location.fy,
      worldX,
      worldZ,
      matchConfidence: confidence,
    });
  }

  return { anchors, unresolved };
}
```

- [ ] **Step 1: Write `server/scripts/generate-great-enemy-anchors.ts`**

```typescript
import { readFileSync, writeFileSync } from 'node:fs';
import { fitAffineTransform, type AffinePoint, type AffineTransform } from '../src/pipeline/affine-fit.js';
import { buildRegionTileSets, matchGreatEnemies, type PinCandidates, type LocationInput } from '../src/pipeline/great-enemy-match.js';

const SURFACE_REGION_IDS = new Set([
  'consecrated-snowfield', 'haligtree', 'mountaintops', 'farum-azula', 'mt-gelmir',
  'altus-plateau', 'leyndell', 'liurnia', 'caelid', 'limgrave', 'weeping-peninsula',
]);

interface ExistingAnchor {
  name: string;
  category: string;
  regionId: string;
  existingFx: number;
  existingFy: number;
  worldX: number;
  worldZ: number;
}

const candidatesPath = 'tools/msb-extractor/output/great-enemy-candidates.json';
const gracesPath = 'tools/msb-extractor/output/sites-of-grace.json';
const anchorsPath = 'tools/msb-extractor/output/calibration-anchors.json';
const locationsPath = 'web/src/map/locations.ts';

const pinCandidates: PinCandidates[] = JSON.parse(readFileSync(candidatesPath, 'utf-8'));
const graces: { graceName: string; mapTileId: string }[] = JSON.parse(readFileSync(gracesPath, 'utf-8'));
const existingAnchors: ExistingAnchor[] = JSON.parse(readFileSync(anchorsPath, 'utf-8'));

function extractNameFromLine(line: string): string | null {
  const singleQuoted = line.match(/name:\s*'((?:\\'|[^'])*)'/);
  if (singleQuoted) return singleQuoted[1].replace(/\\'/g, "'");
  const doubleQuoted = line.match(/name:\s*"((?:\\"|[^"])*)"/);
  if (doubleQuoted) return doubleQuoted[1].replace(/\\"/g, '"');
  return null;
}

const locationsSrc = readFileSync(locationsPath, 'utf-8');
const locationsByName = new Map<string, LocationInput>();
for (const line of locationsSrc.split('\n')) {
  if (!line.includes("category: 'great-enemy'")) continue;
  const name = extractNameFromLine(line);
  if (!name) continue;
  const regionIdMatch = line.match(/regionId:\s*'([^']+)'/);
  const fxMatch = line.match(/fx:\s*(-?[\d.]+)/);
  const fyMatch = line.match(/fy:\s*(-?[\d.]+)/);
  if (!regionIdMatch || !fxMatch || !fyMatch) continue;
  locationsByName.set(name, {
    name,
    category: 'great-enemy',
    regionId: regionIdMatch[1],
    fx: parseFloat(fxMatch[1]),
    fy: parseFloat(fyMatch[1]),
  });
}
console.log(`Parsed ${locationsByName.size} great-enemy pins from locations.ts`);

const regionTileSets = buildRegionTileSets(graces, existingAnchors);

const anchorsByRegion = new Map<string, AffinePoint[]>();
for (const a of existingAnchors) {
  if (!SURFACE_REGION_IDS.has(a.regionId)) continue;
  const points = anchorsByRegion.get(a.regionId) ?? [];
  points.push({ worldX: a.worldX, worldZ: a.worldZ, fx: a.existingFx, fy: a.existingFy });
  anchorsByRegion.set(a.regionId, points);
}
const regionTransforms = new Map<string, AffineTransform>();
for (const [regionId, points] of anchorsByRegion) {
  if (points.length >= 3) {
    regionTransforms.set(regionId, fitAffineTransform(points));
  }
}

const { anchors: newAnchors, unresolved } = matchGreatEnemies(
  pinCandidates,
  locationsByName,
  regionTileSets,
  regionTransforms,
);

console.log(`\nResolved ${newAnchors.length} of ${pinCandidates.length} great-enemy pins:`);
for (const a of newAnchors) {
  console.log(`  ${a.name}: ${a.matchConfidence} (worldX=${a.worldX.toFixed(1)}, worldZ=${a.worldZ.toFixed(1)})`);
}
if (unresolved.length > 0) {
  console.log(`\nUNRESOLVED (${unresolved.length}):`);
  for (const name of unresolved) console.log(`  ${name}`);
}

const merged: ExistingAnchor[] = [
  ...existingAnchors,
  ...newAnchors.map((a) => ({
    name: a.name,
    category: a.category,
    regionId: a.regionId,
    existingFx: a.existingFx,
    existingFy: a.existingFy,
    worldX: a.worldX,
    worldZ: a.worldZ,
  })),
];
writeFileSync(anchorsPath, JSON.stringify(merged, null, 2) + '\n');
console.log(`\nWrote ${merged.length} total anchors to ${anchorsPath}`);
```

- [ ] **Step 1: Write `server/scripts/apply-full-calibration.ts`**

```typescript
import { readFileSync, writeFileSync } from 'node:fs';
import { fitAffineTransform, applyAffineTransform, type AffinePoint } from '../src/pipeline/affine-fit.js';

const SURFACE_REGION_IDS = new Set([
  'consecrated-snowfield', 'haligtree', 'mountaintops', 'farum-azula', 'mt-gelmir',
  'altus-plateau', 'leyndell', 'liurnia', 'caelid', 'limgrave', 'weeping-peninsula',
]);

interface Anchor {
  name: string;
  category: string;
  regionId: string;
  existingFx: number;
  existingFy: number;
  worldX: number;
  worldZ: number;
}

const anchors: Anchor[] = JSON.parse(
  readFileSync('tools/msb-extractor/output/calibration-anchors.json', 'utf-8'),
);
const surfaceAnchors = anchors.filter((a) => SURFACE_REGION_IDS.has(a.regionId));
console.log(`Calibrating ${surfaceAnchors.length} of ${anchors.length} anchors (surface regions only)`);

const byRegion = new Map<string, Anchor[]>();
for (const a of surfaceAnchors) {
  const list = byRegion.get(a.regionId) ?? [];
  list.push(a);
  byRegion.set(a.regionId, list);
}

interface Correction {
  name: string;
  fx: number;
  fy: number;
}
const corrections: Correction[] = [];
for (const [regionId, regionAnchors] of byRegion) {
  if (regionAnchors.length < 3) {
    console.log(`  Skipping region "${regionId}": only ${regionAnchors.length} anchor(s), need >= 3`);
    continue;
  }
  const points: AffinePoint[] = regionAnchors.map((a) => ({
    worldX: a.worldX,
    worldZ: a.worldZ,
    fx: a.existingFx,
    fy: a.existingFy,
  }));
  const transform = fitAffineTransform(points);
  for (const a of regionAnchors) {
    const { fx, fy } = applyAffineTransform(transform, a.worldX, a.worldZ);
    corrections.push({ name: a.name, fx, fy });
  }
}
console.log(`Computed ${corrections.length} corrected positions`);

function extractNameFromLine(line: string): string | null {
  const singleQuoted = line.match(/name:\s*'((?:\\'|[^'])*)'/);
  if (singleQuoted) return singleQuoted[1].replace(/\\'/g, "'");
  const doubleQuoted = line.match(/name:\s*"((?:\\"|[^"])*)"/);
  if (doubleQuoted) return doubleQuoted[1].replace(/\\"/g, '"');
  return null;
}

function applyCorrections(path: string): number {
  const src = readFileSync(path, 'utf-8');
  const correctionsByName = new Map(corrections.map((c) => [c.name, c]));
  const remaining = new Set(correctionsByName.keys());

  const updatedLines = src.split('\n').map((line) => {
    const name = extractNameFromLine(line);
    if (!name) return line;
    const correction = correctionsByName.get(name);
    if (!correction) return line;
    remaining.delete(name);
    return line
      .replace(/fx:\s*-?[\d.]+/, `fx: ${correction.fx}`)
      .replace(/fy:\s*-?[\d.]+/, `fy: ${correction.fy}`);
  });

  if (remaining.size > 0) {
    throw new Error(`Could not find lines for: ${[...remaining].join(', ')} in ${path}`);
  }

  writeFileSync(path, updatedLines.join('\n'));
  return correctionsByName.size;
}

const webCount = applyCorrections('web/src/map/locations.ts');
const clientCount = applyCorrections('client/src/renderer/map/locations.ts');
console.log(`Applied ${webCount} corrections to web/src/map/locations.ts`);
console.log(`Applied ${clientCount} corrections to client/src/renderer/map/locations.ts`);
```

```javascript
// Run via: node --input-type=module -e "$(cat this snippet)" or save to a scratch .mjs and run with node.
import { readFileSync } from 'node:fs';

const locSrc = readFileSync('web/src/map/locations.ts', 'utf-8');
const entryPattern = /\{\s*name:\s*(?:'((?:\\'|[^'])*)'|"((?:\\"|[^"])*)")\s*,\s*category:\s*'([^']+)'\s*,\s*regionId:\s*'([^']+)'\s*,\s*layer:\s*'([^']+)'\s*,\s*fx:\s*(-?[\d.]+)\s*,\s*fy:\s*(-?[\d.]+)/g;
const locations = [];
let m;
while ((m = entryPattern.exec(locSrc))) {
  const name = (m[1] ?? m[2]).replace(/\\'/g, "'").replace(/\\"/g, '"');
  locations.push({ name, category: m[3], regionId: m[4], fx: parseFloat(m[6]), fy: parseFloat(m[7]) });
}

const regionsSrc = readFileSync('web/src/map/regions.ts', 'utf-8');
const regionPattern = /id:\s*'([^']+)'[\s\S]*?shapePoints:\s*\[([\s\S]*?)\],\s*\n\s*\}/g;
const regions = new Map();
let rm;
while ((rm = regionPattern.exec(regionsSrc))) {
  const points = [];
  let pm;
  const pointPattern = /\[([\d.]+),\s*([\d.]+)\]/g;
  while ((pm = pointPattern.exec(rm[2]))) points.push([parseFloat(pm[1]), parseFloat(pm[2])]);
  regions.set(rm[1], points);
}

function pointInPolygon(point, polygon) {
  let inside = false;
  for (let i = 0, j = polygon.length - 1; i < polygon.length; j = i++) {
    const [xi, yi] = polygon[i];
    const [xj, yj] = polygon[j];
    const intersect = (yi > point[1]) !== (yj > point[1]) &&
      point[0] < ((xj - xi) * (point[1] - yi)) / (yj - yi) + xi;
    if (intersect) inside = !inside;
  }
  return inside;
}

const greatEnemies = locations.filter((l) => l.category === 'great-enemy');
let inside = 0;
const outside = [];
for (const loc of greatEnemies) {
  const polygon = regions.get(loc.regionId);
  if (!polygon) continue;
  if (pointInPolygon([loc.fx, loc.fy], polygon)) inside++;
  else outside.push(loc.name);
}
console.log(`great-enemy pins checked: ${greatEnemies.length}, inside region shape: ${inside}`);
if (outside.length > 0) console.log('Outside region shape:', outside);
```

Expected: most or all recalibrated great-enemy pins land inside their region's shape. A small number landing just outside (a least-squares residual, same as Stage 4's one flagged "Forbidden Lands" case) is an acceptable, expected outcome — report any such cases by name rather than treating them as a failure.
